# Requisitos

Projeto: projeto-desenvolvimento-webmobile
Integrantes: Thiago Soares, Gabriel Santos

## Requisitos funcionais

- RF01 - O sistema deve permitir cadastro de usuário.
- RF02 - O sistema deve permitir login e logout.
- RF03 - O sistema deve permitir criar, listar, editar e excluir registros.
- RF04 - O sistema deve validar os dados enviados nos formulários.
- RF05 - O sistema deve exibir mensagens de erro e de sucesso.

## Requisitos não funcionais

- RNF01 - A interface deve ser responsiva (web e mobile).
- RNF02 - As senhas devem ser armazenadas de forma criptografada.
- RNF03 - As credenciais devem ficar em variáveis de ambiente (.env).
- RNF04 - O tempo de resposta das telas principais deve ser de até 3 segundos.

## Regras de negócio

- RN01 - O e-mail do usuário é único no sistema.
- RN02 - Somente usuário autenticado acessa as telas internas.
- RN03 - Registro excluído não pode ser recuperado pelo usuário comum.
